Un proyecto para todo el año

Una flor nueva cada mes y un montón de puntos por aprender.

Cada mes bordamos juntas una flor diferente. Aprovecho ese proyecto para enseñarte puntos y técnicas de bordado nuevos, y poco a poco vas completando tu propio anuario.

Qué vas a encontrar

  1. Una flor nueva cada mes

    Cada mes bordamos juntas una flor diferente, todas dentro del mismo anuario.

  2. Puntos y técnicas nuevas

    Aprovecho cada proyecto para enseñarte diferentes puntos de bordado.
